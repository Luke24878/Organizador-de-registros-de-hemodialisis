# Organizador-de-registros-de-hemodialisis
Para esta herramienta lo unico que se debe hacer hacer es:
1- Descargar la carpeta en formato .zip y descomprimir
2- Darle a Instalar.bat, esto descargara las librerias y todo lo que necesites para usar
3- Una vez que muestre que se ah descargado todo lo necesario cerrar CMD
4- Dar doble click en el archivo Abrir organizador.bat
5- Abrira la interfaz hecha con tkinter y seleccionar el documento, se puede organizar por id de maquina de mayor a menor

Despues de unos segundos se creara una carpeta donde se mostraran todos los achivos pdf y al inicio estara el nuevo archivo pdf ordenado por numero de maquina en el orden que tu hayas elegido
