# Organizador-de-registros-de-hemodialisis
Esta es una herramienta que hice para mi madre, automatiza el proceso de organizar un archivo pdf con mas de 200 paginas con hojas de registros en una clinica de hemodialisis, las hojas estan organizadas por orden alfabetico, el programa separa las hojas y las vuelve a acomodar por ID de maquina, es una herramienta simple que cumple la funcion
